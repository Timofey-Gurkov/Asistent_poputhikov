# Кампус-экспресс 🚗

Приложение для поиска попутчиков между корпусами УрФУ. Быстро найдите водителя или попутчика для поездки между ГУК УрФУ и НВК.

## Возможности

### Для водителей 👨‍✈️
- Создавайте поездки с указанием времени отправления
- Указывайте количество свободных мест
- Устанавливайте свою цену
- Добавляйте контактные данные (телефон или Telegram)
- Отслеживайте, кто принял вашу поездку

### Для попутчиков 🚶
- Просматривайте доступные поездки
- Принимайте подходящие рейсы
- Получайте контакты водителя
- Отказывайтесь от поездки, если планы изменились

### Общие функции ✨
- **Работа онлайн и офлайн** — приложение автоматически синхронизируется между устройствами
- **Карта кампуса** — просматривайте расположение корпусов
- **Простой интерфейс** — ничего лишнего, только самое необходимое
- **Не требует регистрации** — просто введите имя и пользуйтесь

## Установка

1. Установите Python (если ещё не установлен)

2. Установите зависимости:
```bash
pip install flet
```

3. Запустите приложение:
```bash
python main.py
```

4. Откройте браузер по адресу: http://127.0.0.1:8550

## Как использовать

### Водитель
1. Нажмите «Я водитель»
2. Заполните информацию о поездке:
   - Откуда и куда
   - Время отправления
   - Количество мест
   - Цену (можно 0)
   - Контактные данные
   - Номер машины
3. Нажмите «Опубликовать поездку»
4. Дождитесь, пока попутчики примут вашу поездку
5. Когда попутчик сядет в машину — нажмите «Поездка начата»

### Попутчик
1. Нажмите «Я попутчик»
2. Введите ваше имя
3. Выберите подходящую поездку из списка
4. Нажмите «Принять поездку»
5. Свяжитесь с водителем для уточнения деталей
